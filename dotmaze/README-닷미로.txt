[닷 미로 (Dot Maze)] dot-games-host · 접근성 음성 우선 + 외부 자산 표준  2026-07-20

■ 게임: 미로 탈출 (7x5 완전미로, 항상 풀림)
  왼쪽 위에서 출발해 오른쪽 아래 출구까지 방향키로 이동. 벽은 못 지나감.

■ 접근성(눈 없이 플레이)
  · 시작 시 음성 튜토리얼(목표·조작·벽 안내·방향 안내). 첫 게임 자동, H/? 로 언제든 다시.
  · 움직일 때마다 "2행 3열. 갈 수 있는 방향은 위, 오른쪽." 처럼 위치+열린 방향 음성.
  · 벽에 막히면 "벽이에요. 그쪽은 막혔어요." + 낮은 효과음.
  · C(또는 방향 안내 버튼): 지금 갈 수 있는 방향 다시 듣기. 출구 도착 시 걸음 수 안내.
  · DotPad 촉각: 벽=볼록하게 융기, 길=평평, 플레이어=중앙 점, 출구=칸 네 모서리 표식. 걸음 수는 점자 숫자.

■ 조작
  키보드: 방향키 이동 · C 방향 안내 · H 도움말 · N 새 미로.
  DotPad: F1 위 · F2 아래 · F3 왼쪽 · F4 오른쪽 · PanningAll 튜토리얼 · Panning 좌/우 방향안내 · LPF1 새 미로.

■ 레이아웃/디자인: 세로 스택(상태→HUD→미로→안내줄→버튼, 겹침 없음). 미로는 보라/시안 네온 콘솔 톤.
  · 배경 이미지 주시면 .stage 에 넣어드립니다(하던 방식대로).

■ 구조(외부 자산 표준): dotmaze/ = index.html + assets/(배경 이미지) + dotpad-sdk/
■ 배포: dotmaze/ 폴더째 업로드(폴더명 'dotmaze') → 재배포. 확인: dot-games-host.vercel.app/dotmaze/index.html?embed=1&preview=0
■ 인코딩/불변식: EA·encodeFrame(600hex) 그대로.
