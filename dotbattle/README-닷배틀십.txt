[닷 배틀십 (Dot Battleship)] dot-games-host · 시각장애 사용자 우선 음성 설계  2026-07-20

■ 접근성 우선 UX (눈 없이 바로 이해·플레이)
  · 시작하면 '음성 튜토리얼'이 게임 방법을 처음부터 끝까지 친절히 설명(목표·이동·발사·명중/격침·승리·모든 단축키).
    첫 게임에서 자동 재생, 이후엔 짧게. 아무 때나 H(또는 ?) 로 다시 들을 수 있음.
  · 방향키로 이동 → 매번 "3행 2열, 아직 안 쏜 칸" 처럼 위치+상태 음성. 격자 끝에선 "맨 위 줄이에요" 등 경계 안내.
  · 발사(엔터/스페이스) → "명중이에요! 배 2척 남았어요" / "명중, 배 한 척 격침!" / "빗나감. 계속 찾아봐요" 처럼
    결과+남은 배 수를 명확히. 승리 시 축하 + 발사 횟수 안내.
  · 언제든: C 현재 칸 / R 남은 배·발사 수 / B 판 전체 읽기(행별로 다 읽어줌) / N 새 게임.
  · 화면에도 좌표 라벨(행·열 1~5), 진행 HUD(격침 0/3·발사·배 칩), 하단 조작 안내 상시 표시(저시력·보조자용).

■ 조작 요약
  화면/키보드: 방향키 이동 · 스페이스/Enter 발사 · C 현재 칸 · R 남은 배 · B 판 읽기 · H 도움말 · N 새 게임.
  DotPad: Panning 이동 · F1 발사 · F2 현재 칸 · F3 현황 · F4 판 읽기 · PanningAll 튜토리얼 · LPF1 새 게임.
  DotPad 촉각: 명중=칸 채움, 빗나감=십자 점, 커서=칸 내부 사각. 남은 배 수는 점자 숫자.

■ 구조(외부 자산 표준): dotbattle/ = index.html + assets/(선택, 배경 이미지 주시면 wiring) + dotpad-sdk/
  배경/함선 이미지는 기존 방식대로(히어로 1200×420, 썸네일 600×800, 인게임 배경 1800×1120) 주시면 입혀 드립니다.

■ 배포: dotbattle/ 폴더째 업로드(폴더명 반드시 'dotbattle') → 재배포 → 하드 새로고침.
  확인: dot-games-host.vercel.app/dotbattle/index.html?embed=1&preview=0

■ 인코딩/불변식: EA·encodeFrame(600hex) 그대로.
